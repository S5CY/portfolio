# Trimester 1 Project Summary

## Overview

This trimester, I worked on interactive learning tools, AP CSA lessons, and setup resources for students. I contributed to both personal and team repositories, tested and improved existing work, and used feedback to make my projects easier to use.

## Main Projects

### MeiTuan Mouse CSA Delivery

I created a delivery-themed game for reviewing CSA Units 1–4. It includes lesson checkpoints, multiple-choice questions, progress tracking, rewards, and achievements. This project helped me combine course content with JavaScript, interface design, and game mechanics.

- [Play MeiTuan Mouse CSA Delivery](https://s5cy.github.io/portfolio/csa-delivery/)

### Linux Setup Agent and Toolchain Trail

I helped create a Linux setup agent that checks a student's development environment and gives clear troubleshooting steps. I worked on the documentation, Python code, and automated tests. I also helped connect the setup tools to the team's Toolchain Trail game and added voice, language, and pitch options.

- [Play Toolchain Trail](https://the7blueprints.github.io/blueprints_pages/cs-pathway/toolchain-trail)
- [View the setup-agent documentation](https://github.com/the7blueprints/blueprints_pages/blob/main/docs/linux-setup-agent.md)
- [View the Python agent](https://github.com/the7blueprints/blueprints_pages/blob/main/scripts/linux_setup_agent.py)
- [View the automated tests](https://github.com/the7blueprints/blueprints_pages/blob/main/scripts/test_linux_setup_agent.py)

### AP CSA Unit 4 Lessons

I created three student-facing lessons and revised them to better match the class rubric. I improved the explanations, examples, visuals, and interactive practice. I also repaired broken links and file locations in five teammates' lessons so the full Unit 4 collection worked correctly.

- [Lesson 4.6 — Using Text Files](https://the7blueprints.github.io/blueprints_lessons/csa/unit_04/4_6)
- [Lesson 4.7 — Wrapper Classes](https://the7blueprints.github.io/blueprints_lessons/csa/unit_04/4_7)
- [Lesson 4.17 — Recursive Searching and Sorting](https://the7blueprints.github.io/blueprints_lessons/csa/unit_04/4_17)
- [View the team lesson repairs](https://github.com/the7blueprints/blueprints_lessons/commit/f3b7a9db5)

## Learning and Reflection

These projects helped me improve at planning features, using GitHub, writing documentation, testing code, and designing for other students. I learned that finishing the first version is only part of the process. Testing, fixing problems, and responding to feedback made my work much stronger.

I also scored **39/42 (92.9%)** on a College Board practice exam. My [MCQ analysis](https://github.com/S5CY/s5cy_student/issues/10) helped me identify three areas to review: matching constructor arguments, testing algorithms with negative values, and understanding variable scope.
